# Example Work Order and Response

This is an anonymized real example where the assumptions were knocked down by the executor.

## The Work Order

```
# Order — Critique of a pricing proposal for a short video

Read only `inputs/pricing-proposal.md` and `inputs/market-research.md`. Web search is allowed. Every external fact needs a URL opened today and a date. Do not invent prices.

## Goal
1. **Where the proposal is wrong or fragile**, with the reason and citation: structure (what it includes, revisions, deadline), numbers, fee calculation, difference between direct and marketplace, and rush fee.
2. **What a marketplace buyer does with these numbers**: what they compare it to, what they ask, where they give up. Be the buyer.
3. **An unwritten pricing risk** (e.g., a low anchor that stalls the package, one revision becoming five, what happens when client material is bad).
4. **Your counter-proposal**: the same three numbers, with a one-line justification each.

## Assumptions
- The package discount is 12%.
- The 20% marketplace fee calculation is correct.
- Rights constraints (only client networks) align with marketplace terms.

## Evidence Rules
Separate read fact (cite), external fact (URL and date), and opinion. Do not evaluate the entire operation: just the price.
```

## The Response (Snippet)

```
1. **Where the proposal is wrong or fragile**

   - **[READ + CALC] The package discount is wrong.** Four single videos cost 1,040 currency units; 690 currency units is a **33.65% discount, not 12%**. The approximate 12% appears against four pilots, which include fewer revisions. The correct unit price is 172.50. This changes the economic justification of the package.
   - **[CALC] Dividing by 0.8 is right if the deducted fee is 20%.** But 860 leaves **688**, not 690. To preserve exactly the direct package, it would be 862.50.
   - **[OUTSIDE — opened today] "Marketplace" is not a single final price.** On Marketplace A, the buyer still pays a 4.5% service fee and variable processing. **[OPINION]** The column mixes proposed remuneration with buyer outlay; they must be distinguished. (URL, Date)
   - **[READ + OUTSIDE] The rights restriction requires correction.** "Only client networks" diverges from Marketplace B terms, which require broad assignment and publication on any media. **[OPINION]** Do not sell the same scope on both channels without making this promise compatible. (URL, Date)
```

## What Changed Because of This
The executor demonstrated that the stated 12% discount was actually 33.65%, the fee calculation had small errors, and a rights clause contradicted marketplace terms. The requester revised the entire pricing table and scope before publishing.
