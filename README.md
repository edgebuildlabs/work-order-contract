# Work Order Contract

## The Problem
An agent given a vague request returns a confident and wrong result. The request is half the contract. If you don't define the boundaries, assumptions, and required evidence, you get plausible hallucinations instead of usable work.

## What This Is
This is a work order template and a set of rules. It forces the executor to correct the requester. It shifts the burden from "guessing what the human wants" to "proving the work meets the criteria."

## How to Use It in 3 Steps
1. **Copy** `WORK_ORDER.md` for your new task.
2. **Fill** it out, stating your assumptions clearly so the agent can knock them down.
3. **Send** it to your executor (agent or human).

## What This Is NOT
* It is not a magic prompt.
* It is not a software framework.
* It does not require any specific tool, plugin, or installation.

## Companion Piece
